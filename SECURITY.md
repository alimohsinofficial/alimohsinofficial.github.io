# Reporting a security concern
Use the public contact form at https://alimohsinofficial.github.io/contact/ (Subject: Support). Include the affected page, reproduction steps and impact. Avoid secrets and sensitive personal data. The static portfolio does not promise a response time or offer a bug bounty.

The machine-readable contact record is /.well-known/security.txt. This portfolio is public static content; it has no login, payment flow or portfolio backend. Google Forms and GitHub Pages handle their own services. See docs/security-seo.md for implemented controls and hosting limitations. No private email address is published as a security contact.
